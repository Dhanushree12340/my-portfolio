## 🚀 Getting Started

### 1. Open the project in VS Code or Terminal
Open PowerShell or your terminal in this directory:
```bash
cd C:\Users\Dhanu\.gemini\antigravity\scratch\dhanushree-portfolio
```

### 2. Start the Local Development Server
```bash
npm run dev
```
Open your browser and navigate to the displayed local URL (typically **http://localhost:5173**).

### 3. Build for Production
```bash
npm run build
```

### 4. Preview the Production Build
```bash
npm run preview
```
